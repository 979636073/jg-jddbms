# 表与模式的导入导出

## 表级操作

在工作区左侧树右键普通表，选择“导入”或“导出”。文件格式为 SQL、CSV、TSV、XLS、XLSX、JSON、XML；也可选择另一个达梦或 Oracle 数据源进行单表直连迁移。直连迁移创建草稿、执行预检查，必须在审阅页确认后才会写入目标数据库。

文件导入目标是当前已有表，按同名字段追加数据；一次最多 100,000 行、50 MiB。导入使用单个数据库事务，失败会回滚本次导入。SQL 文件里的 CREATE TABLE 只核对表名，不会在表级导入时执行。CSV/TSV 的空字段无法区分空文本和 NULL；需要准确保存 NULL 时使用 JSON 或 XML。二进制字段使用 `BASE64:` 前缀。

文件导出和导入都进入任务中心执行。导出完成后从任务中心下载；导入完成或失败后从任务中心查看行数或错误。表文件可以在达梦与 Oracle 之间双向使用。直连跨库迁移也在后台执行，任务中心的“跨库数据迁移”区域可查看状态并进入审阅页。

## 模式级 SQL

右键模式名，选择“导出 SQL”或“导入 SQL”。表清单支持搜索、分页、多选、本页选择与全选搜索结果。导出固定包含建表 SQL、数据行、索引、约束、触发器、依赖所选表的视图和过程（含函数、包）；空表不会产生 INSERT 语句。模式 SQL 文件采用带对象标记的纯文本脚本，保留每段 SQL 供人工审阅。

模式导入先上传由本系统导出的模式 SQL 文件，再勾选要创建的表，选择“只导入表”或“导入表和数据”。同类型数据库且模式同名时，两种方式都恢复文件中的索引、约束、触发器、视图和过程；跨达梦/Oracle 或跨模式时只创建表，并按选择决定是否导入数据行。所选目标表应不存在；DDL 在达梦和 Oracle 上通常不能随数据事务一起回滚，失败前已执行的对象应按任务错误信息复核。复杂跨库对象请使用数据迁移审阅流程。

一次模式 SQL 最多选择 10,000 张表，脚本大小最多 200 MiB；每张表的数据导出还受表级 100,000 行、50 MiB 限制。运行中的进度及完成后的 SQL 文件均位于任务中心。
