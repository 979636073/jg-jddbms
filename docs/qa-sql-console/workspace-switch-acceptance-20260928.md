# 工作区切换闪屏修复验收（2026-09-28）

## 范围与原因

保留现有蓝白视觉、布局、路由、共享左树及右侧独立缓存，只修复窗口切换的刷新感。验收地址为 `http://127.0.0.1:38080/`，使用 Docker ARM64 前端与真实 DM / Oracle 数据源。

原右侧缓存容器被 `fade-transform`、`mode="out-in"` 包裹：旧窗口先执行 0.5 秒透明/位移动画，随后新窗口再执行 0.5 秒进入动画。内部路由切换还会启动 NProgress 顶部进度条。采样确认左树没有被重新创建或改变尺寸，浏览器也没有发生整页导航；主要问题是动画产生的视觉闪屏，不是重复加载整页。

## 最小修复

- 移除工作区右侧路由外的切换动画，保留 `keep-alive` 及按窗口路径区分的缓存。
- 仅当起点与终点都是 `/workspace/look/…` 或 `/workspace/query/…` 时，不启动整页导航进度条。
- 保留工作区外导航、首次进入工作区的进度提示，以及鉴权流程和所有导航结束时的进度条清理。
- 未删除真实对象打开、SQL 执行等请求的局部加载提示；未修改全局动画样式、数据库查询逻辑或 DMP 功能。

## 逐帧对比

浏览器 `requestAnimationFrame` 对实际点击页签的过程采集 120 帧，同时记录右侧容器的透明度、位移、存在状态，以及左树的 DOM 身份、透明度和尺寸。

| 检查项 | 修复前 | 修复后 |
| --- | --- | --- |
| 右侧透明度低于 1 的帧 | 95 / 120 | 0 / 120 |
| 右侧最低透明度 | 0 | 1 |
| 顶部导航进度条出现帧 | 49 / 120 | 0 / 120 |
| 右侧容器缺失帧 | 0 / 120 | 0 / 120 |
| 右侧变换 | 淡入淡出及水平位移 | 始终 `none` |
| 左树身份、透明度、尺寸 | 始终一致 | 始终一致 |

修复后分别采样查询 → 空白窗口、空白窗口 → 缓存查询，以及连续跨库切换，都没有出现透明帧、缺失帧或整页进度条。

## 功能回归

- DM 只读查询 `SELECT LEVEL ID, 'DM_CACHED' MARKER FROM DUAL CONNECT BY LEVEL <= 405;` 执行并翻到第 2 页，首行 ID 为 201。切到空白窗口再切回，脚本、第 2 页和结果保持；XHR/Fetch 请求数保持 41。
- Oracle 只读查询 `SELECT 'ORACLE_CACHED' MARKER FROM DUAL;` 成功。
- DM / Oracle 查询窗口连续交替切换 12 次，XHR/Fetch 请求数切换前后均为 46；共享树 `innerHTML` 及 DOM 对象完全相同，Oracle 的模式、脚本、结果保持。
- 浏览器未报告新运行错误。本轮没有修改业务表、创建验收表或改动账号授权。
- 新增回归测试在旧代码上失败，修复后通过；14 个前端测试文件全部通过，生产构建通过。
- 三个 `jddbms-arm64` 容器均健康，首页 HTTP 状态为 200。本轮只重建前端容器，后端和 Redis 未重启。
