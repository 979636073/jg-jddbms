# SQL 控制台与窗口缓存验收（2026-09-28）

## 范围

按已确认样稿保留蓝白配色，调整为“上下文栏 → 操作栏 → 编辑器 → 结果区”。本轮不改 DMP 导入导出。

- 每个查询窗口独立保留连接、模式、脚本、结果、分页与事务状态。
- 左侧资源树由整个工作区共享，保留展开、搜索、选中、批量勾选、滚动位置和宽度；新增或切换右侧窗口不恢复另一份树状态，也不自动定位其他节点。只有用户操作左树时才改变它。
- 切换已有窗口不重新查询或重新加载资源树；浏览器刷新仍会重新进入工作区，不属于持久化恢复功能。
- 模式列表按需读取，选中的模式应用到 Oracle / DM 新 SQL 会话；待提交事务期间禁止切模式。
- 执行选中/光标所在语句与执行全部分开；提供停止、超时、遇错继续/停止、格式化、脚本与历史入口。
- 补齐按当前窗口的数据源和模式读取真实表、字段，支持表别名字段与模式前缀。

## 实测修复

| 问题 | 修复与验证 |
| --- | --- |
| 页签切换重复请求、上下文串用 | 右侧缓存独立上下文，左侧只挂载一棵共享树。最终版本 DM 查询 → Oracle 查询 → Oracle 表 → DM 查询，XHR/Fetch 总数始终为 336；各窗口模式、脚本、结果不串用。另测 Oracle 表与查询往返，请求数保持 325，查询第 2 页仍从 201 开始。 |
| PL/SQL 的 END IF、END LOOP 被分拆 | DM / Oracle 保留原 SQL，按引号、注释、嵌套块及独立 `/` 分割脚本；嵌套过程块和随后 SELECT 分别执行成功。 |
| 合法原生查询被本地解析器阻止或无法分页 | 解析失败时仍交由数据库执行；CONNECT BY 查询按 200 行分页，第 2 页为 201～400。 |
| 结果翻页重放批量 SQL | 每个结果只保留自己的原 SQL、上下文与会话；分页不重复执行过程块或其他语句。 |
| 模式只改变下拉框 | Oracle 选 SYSTEM 后 CURRENT_SCHEMA 返回 SYSTEM；DM 选 SYS 后返回 SYS。 |
| 批量结果事务标记被覆盖 | 保留逐条结果的事务标记，错误不自动回滚之前成功的 DML。 |
| 分页按钮被状态栏挡住 | 控制台内解除表格最小高度，保留分页栏高度；真实点击下一页验收通过。 |
| 快捷键被 Monaco 拦截 | 使用捕获阶段监听，只响应活动窗口；Ctrl+Enter 与 F9 已实际执行。 |
| q 引用使后续 SQL 全部变红 | 控制台使用独立 SQL 语言定义，支持四种常见成对 q 引用；后续 SELECT 恢复正常关键字着色。 |
| 多窗口事务会话被后续请求误关 | 单元测试复现并修复线程上下文残留；Oracle 窗口 A 持有行锁，B 等待并超时/取消后，A 仍能读取自己的未提交值，事务没有被 B 的请求误关。使用独立新值验证回滚后恢复基线值。 |
| 请求失败后仅显示“就绪” | 结果区明确提示请求失败、执行状态未确认，保留已知事务状态；不自动重放写语句。前端回归覆盖异常响应。 |
| 配置较长 SQL 超时却先被 HTTP 中断 | 请求等待时间按语句数和 SQL 超时计算并增加 15 秒余量；测试覆盖两条语句、各 120 秒时的 255 秒请求时限。 |
| 小屏结果区被表格标题和内边距挤占 | 查询结果隐藏表数据编辑标题，约束表格高度；1256×620 浏览器中实测可同时看到编辑器和结果行、分页栏。 |

## 测试结果

- 前端 14 个测试文件全部通过；生产构建通过（含后续窗口切换闪屏回归）。
- 本轮选定的后端 30 个用例全部通过（SPI 14，业务 16），包含 SQL 分割、会话、分页策略、请求上下文、控制器、批量结果、审计与高风险 SQL 校验。
- DM 和 Oracle 各执行 `read-only-matrix.sql` 的 6 条语句，全部成功：CTE、UNION、JOIN、窗口函数、CASE、提示注释、q 引用、GROUP/HAVING、CONNECT BY、嵌套匿名块、块后 SELECT。
- 两类数据库均验证真实表字段补齐：`SELECT t. FROM JD_QA_SQL_0928 t` 返回 `ID`、`NOTE`，不是硬编码示例字段。
- 两类数据库均验证 DML 后语句错误时保留已有事务、提交与回滚，以及批量遇错停止（后续 SELECT 不执行）。
- DM 的 `DBMS_LOCK.SLEEP(12)` 实测停止成功，5 秒配置实测返回超时；取消和超时后均回滚验收会话。
- Oracle 无 DBMS_LOCK 执行权限，未修改账号授权。专用表双窗口行锁等待实测：5 秒超时约 6 秒返回；另一轮手动停止返回“SQL 执行已取消”，后续语句不执行。
- 格式化后执行、Ctrl+Enter/F9、历史列表、最近脚本恢复、UTF-8 SQL 文件载入均已实测。普通保存脚本下载至 `C:/Users/LYC/Downloads/JD_SQL_QA_0928.sql`，统一换行符后与验收脚本内容完全一致。

## 验收边界

这是一组已执行的代表性 DM / Oracle SQL 回归，不代表所有数据库版本和所有过程语法均已覆盖。SQL*Plus 客户端命令（如 SET、SPOOL、@脚本等）不是 JDBC SQL，不在本轮兼容范围。格式化器不支持某种语法时保留原 SQL 并提示，不阻止数据库执行。

执行计划、存储过程编译与所有结果导出格式尚未完成本轮真实环境专项验收；DMP 导入导出按要求继续暂停，不计入本轮通过范围。
