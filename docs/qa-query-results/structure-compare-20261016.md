# 结构对比专项（2026-10-16）

## 实现范围

- 单表比较按所选表精确读取索引、约束和触发器，使用绑定参数；不再扫描整个模式再按字符串前缀过滤。
- 不同名称的源表与目标表，按对象自身名称匹配；显式对象名区分大小写。数据库系统生成的名称按完整定义及重复数量匹配，避免内部索引编号造成误报。系统对象定义变化会列为两侧独有，不推测重命名关系。
- 索引比较唯一性、类型、状态、复合字段顺序、升降序、函数表达式；约束比较类型、状态、检查条件、复合字段、外键引用表与逐列映射、删除规则、延迟与验证状态。
- 同一模式内的外键引用模式规范化为当前模式，保留外部模式引用的真实名称。DM 可能按被引用主键顺序重新排列外键列；比较展示实际的子列与父列对应关系。
- 当前 DM 的 `ALL_IND_EXPRESSIONS` 未返回实际函数表达式。缺失时通过 `DBMS_METADATA.GET_DDL` 读取索引定义，使用已有 Druid 解析索引字段；忽略尾部物理存储选项。无法完整读取或解析时标记该类对象无法判定。
- 整库汇总同时计算字段与表属结构对象差异，展开表可查看具体对象。索引或约束变化不会再被“字段一致”掩盖。对象读取失败、引用目标不可见、清单超过 20,000 行上限时，不将缺失信息判定为一致；相关类别不完整时，匹配表的汇总保守显示“无法判定”。
- 页面展开区与打印报告展示属性的源值和目标值；数据库文本经转义后输出。重新比较字段时刷新元数据缓存。

## 边界

- 本轮真实数据库验收为本地 DM；Oracle 沿用目录查询实现并完成编译与自动化测试，尚未进行本轮实库验收。
- 比较的是本阶段列出的可见结构属性；不覆盖物理存储、分区、位图或特殊索引的全部选项，也不判断不同 SQL 表达式的语义等价性。
- 本阶段提供结构差异展示与报告，不执行同步 DDL，不生成数据同步脚本。不同表名的自引用外键仍按实际引用表名称展示差异。
- 元数据通过多次只读请求读取，不是数据库级一致性快照；比较期间发生 DDL 时应重新比较。
