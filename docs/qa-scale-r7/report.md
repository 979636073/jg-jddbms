## ISSUE-001：首次打开空表，底部行数缺少 0

- 严重程度：Low；分类：功能 / 状态展示；状态：已修复并实库页面回归。
- 步骤：连接 SYSDBA → 展开 JQDM4_260926 / 数据表 → 搜索并首次打开 QR7_C821_399（400 表亦可复现）。
- 实际：表格“暂无数据”，分页“共 0 条”，底部却为“【查询行数】 行”；刷新数据后才显示 0。
- 预期：首次打开就显示“【查询行数】 0行”。
- 修复：底部提示使用与分页一致的规范化 total，不再直接输出可能为空的原始 fuzzyTotal；不改 SQL 或分页请求。
- 新增渲染回归覆盖缺省、null、0、估算总数和精确总数。修复前失败，修复后通过。
- 页面回归：空表首次打开正确显示 0；非空 10,001 行表的首批仍显示“至少 101行”，没有把估算值标为精确总数。
- 证据：[修复前稳定复现](screenshots/empty-first-repro.png)、[修复后空表](screenshots/empty-fixed.png)、[修复后非空表](screenshots/nonempty-fixed.png)。
