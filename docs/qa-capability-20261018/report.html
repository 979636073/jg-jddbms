发现与处理

DM 普通账号读取普通/物化视图失败 · FIXED_AND_RETESTED
原查询直接访问 SYS.SYSOBJECTS，普通账号返回 -5504。 仅在该权限错误时回退 ALL_MVIEWS，并通过 SF_GET_SCHEMA_NAME_BY_ID(SCHID) 关联模式；其他错误继续上抛。 普通账号真实库 + 管理员真实库 + 7 项目录单元测试 + 当前运行后端 HTTP 分类验证均通过。

历史 Oracle 专用 QA 连接恢复 · RECOVERED_AND_RETESTED
旧 QA 连接保存的密文无法由当前及现有历史密钥解密，且地址为容器宿主别名。 私下备份原密文，仅重置本地 JQORO_260926 专用测试账号密码，以现有密钥重新加密，并将此本地连接地址改为回环地址。 原连接 ID 219 凭据读取与 SELECT 1 真实 HTTP 查询通过；没有更换平台密钥或其他账号密码。
