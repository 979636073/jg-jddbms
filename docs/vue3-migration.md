## 顺序完成的改造

1. 升级运行时、路由、状态管理与 UI 依赖，建立可构建、可启动的兼容基线。
2. 数据库工作区切换 Vue 3 响应式写法，替换 $set/$delete；迁移资源树、缓存窗口、快捷键和生命周期。连接对象更新时保留共享管理权限字段。
3. 通用组件使用 modelValue / update:modelValue；富文本编辑器保持非响应式实例，迁移上传、头像裁剪及日期格式和默认时间类型。
4. 表单设计器使用 vuedraggable 4 的 item-key / item 插槽，替换 Vue 2 render/JSX 和生成模板的旧插槽接口；修复选项树及弹窗双向绑定。
5. 管理页面和表结构组件适配原生 Vue 3 插槽作用域；修复重定向渲染与日志页被工作区缓存路由覆盖的问题。
6. 移除兼容层，迁移浏览器测试辅助代码，执行角色、共享、BLOB、结构对比与生产包冒烟。

虚拟资源树仍依赖 Element Plus 内部 TreeStore。依赖已锁定；以后升级 Element Plus 时，必须重新验证该内部 API 边界。轻量事件总线自己的 $on/$off 是项目接口，已保留。

## 截图反馈后的视觉修复（2026-10-19）

前一轮构建和功能回归没有覆盖所有视觉状态，不能据此认定整个前端已完成验收。本轮根据用户截图修复以下问题：

- 公共输入框主题改用 Element Plus 的输入组件变量；移除内部 input 的背景和焦点光圈，让外层 wrapper 绘制统一边框。保留原有品牌色、错误和禁用状态。
- 登录框通过组件高度变量控制尺寸，密码显隐图标使用正常布局，避免输入区域和前后缀错位。
- 树搜索框的背景、圆角和高度作用于完整输入控件，修复图标与文本区域底色分块。
- 表格行内编辑器使用透明背景和无内框样式，保留单元格选中边框，避免多重边框叠加。
- 高级查询的字段、条件和值保持同一行；底部分页空间不足时换行，执行信息保持横向显示。

本轮使用 8081 生产包检查了登录文本/密码聚焦、密码显隐、两项空值校验、树搜索输入与清空、连接弹窗的 5 个输入框、数字编辑 Esc 取消、文本编辑 Tab 暂存与撤销、字段检查器 NULL 禁用状态、文本域聚焦及高级查询布局。编辑测试未保存至数据库。1536×864 视口下三个高级查询控件同排，执行信息高度为 15.5px；另将表格区域临时约束为 900px，验证分页换至下一行且不重叠，测试后恢复宽度。

核心回归 42 项通过；本轮涉及的 3 个 Vue 文件 lint 为 0 错误、116 项警告；生产构建成功。截图与运行结果保存在 .local/vue3 的 login-after.png、search-before.png、search-after.png、table-edit-final.png、advanced-input-final.png、input-styles-acceptance.json。以上覆盖范围不代表所有业务页面和所有交互状态均已验收。

## 管理界面布局与控件尺寸修复（2026-10-19）

本轮根据个人中心和平台用户截图修复侧栏消失及管理控件过小的问题。侧栏根因是 Vue CLI 5 下普通 SCSS 默认导入没有提供 JavaScript 主题对象，导致读取 menuBackground 时渲染失败；新增 CSS Modules 导出入口并修正三个消费位置。侧栏和顶部导航的旧 el-submenu 同时迁移为 Element Plus 的 el-sub-menu，验证展开、折叠及窄窗口抽屉。

管理区输入框、下拉框和表单按钮统一为 36px 高度、14px 字号，普通工具栏按钮至少 32px，表单项间距 20px。此尺寸作用于管理区和弹窗，工作区表格行内编辑保持原有密度。个人中心限制内容宽度为 1120px、密码表单为 520px，卡片按内容自然撑开；标题统一为 22px。另修复操作按钮换行、日期列过窄、任务状态下拉宽度及长任务消息撑高表格的问题。弹窗增加视口宽高约束，分页允许换行。ThemePicker 增加明确根节点，修复隐藏样式未传递造成的页面底部多余滚动。

使用 8081 生产包在 1560×905、1280×720、768×1024 三种视口下检查个人中心、平台用户、平台角色、在线用户、数据库运行监控、操作日志、登录日志、导入导出客户端和任务中心，共 27 次页面检查、396 个布局断言通过。覆盖导航展开/折叠、控件尺寸、内容溢出、密码空值校验，以及新增用户、新增角色和日志详情弹窗；没有提交业务数据修改。另对工作区、数据迁移、表结构对比作只读加载冒烟，无新 Vue 渲染异常或页面横向溢出。

核心回归 42 项通过；本轮 Vue 文件及新增脚本 lint 为 0 错误、16 项既有警告；生产构建成功。可复用浏览器检查脚本为 jd-dbms-ui/tests/management-layout-browser-qa.js，使用已登录管理员的 agent-browser 会话执行；截图和逐项结果保存在忽略目录 .local/vue3/management-layout。以上为本轮视觉及指定交互覆盖，不代表全部业务 CRUD、所有角色和所有弹窗均已重新验收。

## 性能实测

基线与升级后数据分别保存在 vue3-performance-baseline.json 和 vue3-performance-after.json。同为开发包、已登录热页面、10000 树节点与 1000 行 SQL；双帧采样包含浏览器调度，并非纯输入延迟。

| 指标 | compat 基线 | 原生 Vue 3 |
| --- | --- | --- |
| 树挂载 | 166ms | 217ms |
| 实际树 DOM 节点 | 34 | 34 |
| 滚动双帧中位 / 最大 | 17 / 28ms | 17 / 22ms |
| SQL 编辑双帧中位 / 最大 | 17 / 17ms | 17 / 25ms |
| 采样期间长任务 | 无 | 无 |
| 页面堆内存 | 186MiB | 257MiB |
| DOMContentLoaded | 200ms | 116ms |

这组单次样本不能证明整体提速。热页面加载模块与历史操作会影响内存，DOMContentLoaded 也不构成生产冷启动对比。升级后保持了树虚拟化和无长任务的采样表现；若继续以性能为目标开发，应另做同一生产环境、相同操作序列的重复采样，再针对瓶颈优化。
