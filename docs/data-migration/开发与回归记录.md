# 数据迁移正式开发与回归记录

日期：2026-09-29。前面章节为各轮历史记录，包含当时未完成项。用户已澄清只要求商业工具级功能，不要求商业发布；当前交付以末尾“工具级功能收尾”和 [功能支持矩阵](支持矩阵与发布门槛.md) 为准，许可/发布签字不作为本轮开发阻塞。

## 已实现的能力

- 个人中心管理导航新增“数据迁移”，独立任务列表及六步向导；保留原有蓝白主题、12px 正文、工作区导航和共享资源树。
- 源端、目标端使用独立 JDBC 连接，支持 DM→DM、DM→Oracle、Oracle→Oracle、Oracle→DM；仅在用户点击连接时读取该端模式，不切换工作区 SQL 会话。
- 选择单个源模式、搜索及分页选择最多 100 张普通表，配置目标模式与目标表名称。
- 仅结构、仅数据、结构与数据；仅数据要求预建兼容空表。目标同名默认阻断，可明确跳过；不提供清空、删除重建、追加、自动恢复。
- 元数据与源/目标 DDL 只读预检查，公开类型转换及阻断项；修改配置即使评估失效，10 分钟后要求重查，执行前再次校验配置、授权及结构漂移。
- 普通字段、主键、表/字段注释、字面量默认值及 NULL 定义。精确数值、字符/国家字符、无时区微秒时间、RAW/二进制、BLOB/CLOB/NCLOB 按明确规则搬运；DATE 显式转换为 TIMESTAMP(0)。
- 后台单任务、单写入器，普通字段有界批次，LOB 逐行流式搬运，不经前端 Base64；显示真实阶段、已确认提交行数与 LOB 读取量，不编造百分比。
- 全量内容摘要与行数校验，保留重复行次数，忽略行顺序；内容不一致不能标完成。结构模式核对字段、默认值、主键及注释。
- 任务复用既有 TASK 表持久化，无新增表升级脚本；各接口按所属用户隔离。配置仅保存数据源引用，不保存口令、JDBC URL 或业务行内容。
- 取消回滚未提交批次，保留并报告已提交数据/DDL；提交不确定标记待核对，应用重启标识中断任务，不自动重试。关闭页面不终止后台任务。
- 任务查看、复制配置、日志与 JSON 报告；运行后的配置只读。

## 使用与安全边界

入口：个人中心管理导航 → 数据迁移。依次配置连接、对象、映射策略、预检查、审阅确认离线条件、执行与验收。

源数据及结构必须冻结，目标所选对象禁止业务并发写入。本版不是 CDC，也没有数据库级一致性快照。源端迁移引擎只生成 SELECT；目标只执行生成的建表/注释和绑定 INSERT，不执行用户任意 SQL。

源/目标同类型、同名模式且表名重叠时保守阻断，即使连接 ID 不同；本版尚不能可靠证明它们不是同一物理对象。使用独立目标模式或目标表名。SSH 隧道数据源不进入本版执行范围。

唯一/外键/复杂检查约束、额外用户索引、触发器、程序对象、分区/生成列等尚未迁移，不应当作完整业务模式迁移工具。不可支持的定义或类型应显示阻断；浮点、时区、BFILE、用户定义类型及表达式默认值暂不适配。物理存储、授权及账号不会复制。

取消在数据库响应和安全批次边界生效，单条查询超时设置为 300 秒，不承诺瞬时取消或全任务事务回滚。待核对、中断或失败后先查看目标已生效内容，禁止盲目重跑。仅支持单后端实例执行，不提供分布式队列。

## 回归中处理的问题

1. 时间字段不再经过 JVM 时区/驱动 Calendar 转换，使用数据库显式格式传输民用时间，保留微秒。
2. CLOB 不以 SQL 字符长度作为 Java UTF-16 Reader 长度，读取到 EOF，避免补充字符导致截短。
3. 达梦默认内部无逻辑列的 CLUSTER 索引、Oracle 自动 LOB 索引不误认为待复制的业务索引；额外用户索引仍阻断。
4. DM 当前版本将 NCLOB 暴露为 TEXT，显式走国家字符 LOB 映射和预览，不退化为普通字符串。达梦官方文档将 TEXT 列为长文本类型；具体 NCLOB/TEXT 目录行为由本次实库验证，不推断所有版本一致：[数据类型](https://eco.dameng.com/document/dm/zh-cn/sql-dev/dmpl-sql-datatype)。
5. 达梦驱动的 Reader 分块编码在 UTF-16 代理对跨块时会替换字符；按目标实际字符集先做有状态、有界流式编码，再以明确 CLOB/NCLOB 类型绑定字节流。国家字符和多 LOB 同行的四方向全量摘要回归通过；GB18030 路径尚未实库验证，不能据此宣布该字符集商用兼容。使用现有 Commons IO 的 [ReaderInputStream](https://commons.apache.org/io/apidocs/org/apache/commons/io/input/ReaderInputStream.html)，未修改或重分发驱动源码。
6. 结构迁移检查源表全部触发器，包括禁用状态，避免未复制触发器却将结构标记完成；仅数据模式仍禁止目标启用触发器产生副作用。
7. 迁移页设置独立内容滚动区域，避免管理页容器的隐藏溢出裁掉底部任务日志及向导操作。

## 工具级功能收尾（2026-09-29，用户澄清后）

### 本轮实现

- 表级有界并发默认 1，可选 1～4。每表独立连接，按显式依赖分波次，共享任务行速率/提交计数；LOB 表共用一个执行槽。启动的写入器全部退出后才记录终态，不提前释放活动任务。最大发起 10 个源/目标连接，不含控制库等连接。
- 多写入器提交前持久记录待确认提交数量，单个线程不能覆盖另一线程的 COMMITTING；计数及 LOB 统计有锁保护。不确定提交/检查点失效仍 NEEDS_REVIEW，已确认且经恢复核对后才解除标记。
- 默认及单表目标表空间映射，核对在线永久空间及实际建表目录；不移动仅数据既有表、不创建空间/改配额，不复制索引物理布局。
- 显式 NUMBER/VARCHAR/NVARCHAR/RAW/TIMESTAMP 类型 CAST、最多三层标量属性路径、逐字段业务语义确认；修改后取消旧确认。不允许任意 SQL、静默类型降级或丢弃非空默认值。转换字段与筛选组合阻断，转换主键使用新目标重迁移。校验的是转换后的内容，不宣称整个 UDT 无损克隆。
- 选择未完成对象（或所有未完成对象）创建关联新目标草稿，包括必要依赖；保留原任务/目标，完整重走连接、审阅和预检查。无稳定键/无旧基线/仅结构/程序可选此流程，程序 DDL 与确认清空，须重写引用；追加失败不自动再次追加。新目标名字按 UTF-8 字节限长，避免中文名称超过 Oracle 11g 字节上限。
