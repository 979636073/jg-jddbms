## 二、对象及策略

| 能力 | 当前实现 | 实库验收 |
| --- | --- | --- |
| 普通表、字段改名、注释、主键、保守类型、LOB | 自动预检查/生成/搬运/全量摘要 | 四方向通过 |
| 普通升序索引、唯一约束、基础 CHECK、已选表外键 | 数据后创建，实际目录验证 | 四方向通过 |
| 多模式、逐对象目标模式 | 选择保留、冲突和依赖识别 | 单元/UI 通过；Oracle 两个独立 QA 模式、逐对象目标模式及完整摘要实测通过；其他跨模式矩阵未测 |
| 同名阻断、显式跳过 | 默认阻断；跳过结果为 PARTIAL | 四方向基础引擎通过 |
| 追加、清空后写入、删除重建 | 全局默认 + 单对象覆盖，实际高风险目标二次确认；重建不级联 | 四方向实际服务/TASK 测试通过 |
| 源数据筛选 | 每表最多 20 个 AND 条件，真实源字段、参数绑定；读取/基线/校验/恢复一致 | 四方向数值、LIKE、微秒时间及 IS NOT NULL 通过；筛选外目标行恢复阻断通过 |
| 复制行速率 | 0 不限；1～100000 行/秒；任务共享节流，提交批次最多一秒速率；允许批次突发，等待可取消 | 本机/ARM 单元通过，四方向带限速工作流通过；不是 LOB 字节或生产吞吐 SLA |
| 视图、同义词、序列 | 采集源定义、人工目标 CREATE、依赖及可读/有效性检查 | 四方向专用 QA 样本通过 |
| 过程、函数、包规范/包体、触发器 | 人工转换、显式确认、依赖排序、有效性检查；触发器最后创建及状态保留 | 四方向简单样本通过；不承诺任意业务语义等价 |
| 表级并发 | 默认 1，可选 1～4；独立连接、依赖波次、单 LOB 表槽、共享速率及提交计数，全部写入器退出才记终态 | 四方向并发 3 实库通过；计数/状态/节流单元通过；DM 并发 LOB 取消本机及 ARM 综合回归通过 |
| 目标表空间 | 默认及单表覆盖；只选在线永久空间；不移动仅数据既有表、不创建空间/改配额 | 四方向创建表的实际目录核对通过；Oracle 零配额失败及专用用户修复后重迁移通过 |
| 显式类型转换 | 受限 NUMBER/VARCHAR/NVARCHAR/RAW/TIMESTAMP CAST，标量属性路径及语义确认；未知类型仍默认阻断 | 数值精度转换四方向通过；Oracle UDT 单属性→DM/Oracle，舍入与 NULL 完整校验通过；不是完整 UDT 克隆 |
| 受限恢复 | 源结构/全量摘要稳定；有支持类型的主键；目标已有行内容一致，只补缺失 | 四方向取消/篡改阻断；纯表 MVC 持久化恢复通过 |
| 独立失败继续 | 默认 STOP；显式选择 CONTINUE_INDEPENDENT 后，仅 SQLState 22/23/42 的确定错误可继续；回滚失败、检查点失败、取消及不确定提交仍停止 | 四方向真实服务/TASK 约束失败、独立成功及依赖阻断通过；不是忽略坏行 |
| 单对象受限重跑 | 对未完成普通表先检查稳定主键、源端基线、目标归属/内容及已完成依赖；确认后只补该表缺失行，保留日志/次数和其他对象 | 四方向真实服务/TASK 重跑通过，成功表不重复写入；无主键/追加/仅结构等仍阻断 |
| 新目标完整重迁移 | 选择未完成对象及必要依赖，生成关联新草稿/新名称，保留旧目标；无稳定键/无基线/仅结构/程序可重新完整预检查执行，程序 DDL 重审 | 无主键四方向实库通过；Oracle 配额修复后的新目标任务通过；程序依赖纳入和确认清空单元通过，程序新目标专门故障重跑实库尚未单独覆盖 |
| 程序混合任务、追加任务自动恢复 | 不支持旧目标盲目续迁；可选新目标完整重迁移 | 自动恢复阻断路径通过 |
| 真实 HTTP 认证链 | 隔离 QA 登录用户，复用现有 SecurityConfig、JWT、Redis 会话；真实网络请求及后台 JDBC/TASK | 本机及 ARM：匿名拒绝、所属用户、重复启动、独立请求刷新、50 行完整校验通过；不是生产用户表/验证码完整测试 |
| 故障及强停 | 真实 QA TCP 连接切断、权限/配额失败；独立 ARM64 容器 SIGKILL、新 JVM 重建核对及续迁 | 本机及 ARM 定向网络故障通过；权限/零配额通过；ARM 强停后复用 48 行，最终 200 行唯一且完整摘要通过。提交成功后应用响应异常由包装层注入，不是抓包证明线路丢失 ACK |

字段类型以实际预检查为准。DATE 转 TIMESTAMP(0)，时间按民用字段传输，不经过 JVM 时区转换。空字符串/NULL、负标度、字符长度和默认值不能自行推断跨库一致。时区/浮点特殊类型、BFILE、未配置可验证 CAST/标量属性投影的用户定义类型、表达式默认值等未适配项阻断。

以下不在当前自动迁移范围：分区/物化视图、虚拟/自增列、函数/降序/位图及特殊索引、禁用/延迟/NOVALIDATE 约束、失效/不可见普通索引、物理存储/授权/账号/系统任务。逻辑约束及用户索引使用生成的安全名称；支持新建表表空间映射，不复制索引物理名称/表空间/优化器属性，不是物理数据库克隆。

序列目标起点须人工评审，不调用源 NEXTVAL 推进业务序列；缓存序列的 LAST_NUMBER 不是下一次精确返回值，参见 [Oracle 11g ALL_SEQUENCES](https://docs.oracle.com/cd/E24693_01/server.11203/e24448/statviews_2062.htm)。

DM 普通外键的内部 VIRTUAL 索引不转换成业务 B-tree，由目标外键创建；特有 WITH INDEX/聚集选项不承诺保真。参见 [DM 管理索引](https://eco.dameng.com/document/dm/zh-cn/pm/manage-index)。

## 三、资源基线（非 SLA）

单次 DM→DM 样本：10,001 行、8MiB BLOB、1,200,000 字符 CLOB；只统计此测试阶段，不代表整个应用峰值。四方向小样本另验证 128KiB BLOB、Unicode/NCLOB 和空/NULL LOB。

| 环境 | JVM 上限 / 容器限制 | 复制耗时 | 基线+复制+校验 | 复制行速率 | 堆池各自峰值之和 |
| --- | --- | --- | --- | --- | --- |
| Windows amd64 Java17（本轮全回归） | JVM 约 8GiB，未限容器 | 1.152s | 2.599s | 约 8,679 行/s | 约 156MiB |
| Docker ARM64 模拟 Java8（本轮 77 用例综合中的资源样本） | -Xmx256m，512MiB / 2 CPU | 12.131s | 32.439s | 约 824 行/s | 约 75MiB |

堆池峰值之和不是同时发生的已用堆，也不是 RSS/容器峰值；不包含全部驱动/native/应用内存。ARM 数值含跨架构模拟开销，不可用来预测生产 ARM 吞吐。资源样本自身完整摘要通过；该轮综合另外有 1 个故障代理测试失败，修正测试代理关闭行为后定向补测通过，不能将原综合运行改记为全通过。结果保存在 `target/migration-performance-aarch64.json`，单次波动不当作性能承诺。尚无最大规模/单 LOB/并发用户、长时间压力、完整应用 RSS 及停机 SLA 验收。此前 41/42/50/60 用例为历史回归，详见开发记录。
