# 视图目录和交互性能修复验收（2026-10-16）

## 变更范围

- DM、Oracle 的视图清单统一按 `SYS.ALL_OBJECTS.OBJECT_TYPE` 分类，不再依赖 `ALL_MVIEWS`，目录异常仍向用户反馈。
- 表首屏跳过精确计数，先显示当前页，再单独统计总行数；计数超时 15 秒，失败保留数据和手动统计入口。计数使用现有表读取权限，不增加任意 SQL 权限入口。
- 对象打开期间显示明确的加载状态。
- Monaco 编辑器实例、模型相关对象和补全缓存不再进入 Vue 深度观察；补全延迟、取消检查、限制 SQL 上下文长度、复用进行中的元数据请求，表名补全使用轻量树接口。
- Oracle 元数据批量抓取 200 行，结果分页按当前页限制抓取量；Oracle 禁止预取 LOB 正文，预览/下载继续按需读取。
- Oracle 连接和登录默认限时 5 秒；DM/MySQL 使用毫秒制连接超时，PostgreSQL/Kingbase 使用秒制，保留显式高级属性。
- 资源树按表名及注释搜索已连接数据源；可加载未展开的模式和表分组。清空搜索或选择其他数据源对象后，恢复其他节点在搜索前的展开状态。迟到请求不能重新展开已恢复的节点。

## 本地实库和页面结果

使用用户登录的浏览器会话、`本地DM` 连接及 `TEST-TEST` 模式，未修改已有表数据和授权。

| 验证项 | 结果 |
| --- | --- |
| 普通视图 | `TEST_VIEW3` 正确列入普通视图，打开显示 3 行数据 |
| 物化视图 | `TEST_VIEW` 正确列入物化视图，打开显示 3 行数据，无 `ALL_MVIEWS` 错误 |
| 视图清单 | 首次接口约 163ms，后续分组请求约 56–57ms |
| 表目录 | 11 张表含注释，接口约 231ms |
| 注释搜索 | “图片”命中 `BLOB_LARGE_TEST_20261015`，返回 `TEST-TEST` 模式；接口约 115ms |
| 未展开节点 | 注释搜索可展开未展开的模式；将数据源收起后再次搜索会临时展开，清空后仍保持原来收起状态 |
| BLOB 首屏 | 100 行正常显示，数据接口约 348ms、响应体约 12KB；后台计数约 59ms，分页补齐总数 1029 条 |
| 加载反馈 | 点击对象后出现“正在打开对象，请稍候…” |
| 编辑器 | 浏览器中确认实例没有 Vue `__ob__`；一万行脚本加载约 11ms，20 次同步编辑单次最高约 3ms，结束后恢复原脚本，未执行测试脚本 |
| Oracle 超时 | 本机模拟“TCP 接受连接但不完成 Oracle 握手”，实际 JDBC 21.1 驱动约 5066ms 返回超时 |

以上是本机单次样本，不作为现场数据库性能承诺。截图见 [物化视图结果页](screenshots/materialized-view.png)。

## 尚需现场验证

本地已有两个 Oracle 连接均在建立连接前报“数据源密码解密失败，请检查加密密钥”，无法据此对比现场原先约 10 秒的目录和表查询。Oracle 路径已通过代码回归及真实驱动超时试验，但 Oracle 实库目录、数据和 LOB 性能仍需在可用连接上复测。

现场应验证普通视图、物化视图均能列出和打开，以及同一模式表清单、同一表第一页数据的前后耗时。若仍失败，应记录具体数据库版本、接口和完整错误原因，不能将失败转成空列表。
